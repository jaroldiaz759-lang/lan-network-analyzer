#LAN Network Analyzer

###Analizador de redes locales desarrollado en Python

##LAN Network Analyzer es un proyecto educativo diseñado para analizar y comprender redes LAN mediante herramientas desarrolladas en Python.

##Objetivos del proyecto

- Analizar direcciones IPv4.
- Calcular direcciones de red y broadcast.
- Identificar rangos de direcciones IP utilizables.
- Comprobar la conectividad entre dispositivos.
- Detectar equipos activos en una red local.
- Generar informes básicos de diagnóstico.

##Tecnologías

- Python 3
- Git
- GitHub
- Redes TCP/IP
